# Guided project creation

Build one six-step creation experience: **Pick a source → Review the post → Choose your output → Write your words → Make your content → Review and download**.

- Use the existing visual style and controls, with a shared step indicator, Back/Next navigation and Save and close. Collapse the indicator on phones.
- Save owner-private drafts automatically, including the current step, source, choices, writing and linked production project. Show drafts in Projects and resume the saved step.
- Keep analysis, optional ideas, hooks, captions, storyboards, media and rendering behind explicit actions. Display existing costs; do not change prices or run generation.
- Bring the film storyboard, references, still approval, animation and delivery into the same shell. Reuse existing production tools and preserve rights, quotes, balances and refunds.
- Remove competing angle generators, repeated source summaries and duplicated creative-brief summaries from creation. Keep evidence in the review step and editable preferences in their own step.
- Test save/resume and verify signed-in desktop/mobile navigation without generation.

## Technical details
Add an owner-scoped draft table and authenticated save/load/list functions. The shared wizard links drafts to existing content/film projects rather than replacing their generation or billing logic. Existing studio routes remain available for previously saved work; posting remains a download/copy handoff, not automatic publishing.
