# Project architecture
- Film publishing reuses the shared Upload-Post engine and metered copy, with publish choices persisted in project wrapup and the existing wizard draft retaining its publish position; connection returns are restricted to the current app origin.
- Reel and film voices use shared browser-safe source-evidence matching and a curated ElevenLabs catalog; manual overrides persist and the server validates selected IDs so matching never requires a paid call or clones source identity.
- Film review preserves completed shot attempts with owner-validated revision-compatible selection, saves instructions as history and submission snapshots, and stores audio choices in private project settings plus existing wizard drafts so switching versions never generates paid media.
- Inspiration reels and films use saved owner-private remix directions/instructions with atomic, free per-shot storyboard prefill; selected character/product/setting reference IDs persist per scene so library defaults cannot override identity choices.
- Owner-authorized film proofs are imported offline with server-only credentials and provenance; narration is restricted to server-written proof metadata, preserving normal unpriced-generation blocks.
- Film narration targets summed saved-scene duration using a measured voice rate; MP3 frame duration and speech alignment must pass coverage before saving, with at most one timing regeneration to prevent silent gaps and clipped speech.
- Video inspiration is a separate authenticated studio with server-written owner-readable tables, revision-bound still approvals and atomic attempt/debit claims; unset verified cost configuration blocks paid generation rather than inventing prices.
- Studio rates and video add-on units/packs share one browser-safe configuration; approval and purchase availability are independent flags. Video credits have a separate append-only ledger, atomic claims and debit-backed refunds, with persisted billing currency preserving historical refunds; nonvideo ACTION_COSTS remain unchanged.
- Hosted assembly uses Shotstack JSON timelines, atomic project-scoped debit claims, durable provider IDs and token-verified callbacks that re-poll the provider; unknown submissions never trigger automatic paid retries, and owner-open recovery retries private collection only. AWS API connector supports direct Lambda invocation if Remotion is revisited, so no custom bridge is required.
- Inspiration animation uses the approved still as Veo's first frame; product ingredients populate still generation because Veo forbids mixing first-frame and ingredient inputs. Collection uses durable gateway IDs and never recreates paid jobs.
- Video inspiration motion prompts use a browser-safe action/end-state builder; model defaults remain provisional until live action/identity gates pass, avoiding camera-only success claims.
- Creator writing uses copy-engine.server.ts (native streamed Claude Messages, local Zod validation and one repair); media observation and image/audio/video providers remain separate.
- Copy quality is judged per artifact with task-specific criteria and at most two regenerations; failures are withheld and flow through attempt refunds, and cache version changes when the quality contract changes.
- Carousel deterministic text compositing executes only in the browser on a generated background; server OCR re-verifies before marking it ready, avoiding native image dependencies in the deployed runtime.
- Copy run history/cache is owner-readable and server-written; an atomic claim precedes debit, failure refunds its attempt, and stale sweeping checks actual debits before refunding.
- A2/A3 carousel rendering reads slide 1 and previous slide from saved assets and verifies exact intended text; free retries are bounded at two and flagged final output refunds its slide.
- The A1 + image quick-generate shortcut still exists in IntentFlow.tsx (one-click clone panel calling quickGenerate); the editable rights-checked slide flow is the alternative for reviewing text before paid generation.
- Clone mode names and summaries share a browser-safe display mapping keyed by unchanged A0–A3 IDs, preserving saved preferences and generation behavior when labels change.
- Modes that reuse source media (A0/A1) require a versioned rights_confirmations row, checked server-side in every entry point (enforceRights), never only in the UI.
- Same-look slide edits use gateway image edits with source-matched size, then a Claude vision gate (exact normalized text, no residual text, same composition) with free retries and a per-attempt refund when flagged.
- Intel analytics are calculated and evidence-checked in a browser-safe pure module before persistence; AI supplies interpretation, not numerical truth.
- Intel AI requests use native streaming Claude Messages in a server-only helper; credentials and prompts never enter browser bundles.
- Intel-to-Studio handoff creates ordinary saved projects using existing project fields and routes, so other studio modules need no changes.
- Research PDF generation stays client-side with jsPDF and nine fixed editorial pages, avoiding server-only rendering dependencies.
- UGC motion uses equal-width repeated groups and a CSS transform loop; visibility arbitration pauses every nonselected copy before playing at most one copy per creator to avoid duplicate playback.- In-flight research reports carry a last_progress_at heartbeat; a DB sweep (hourly pg_cron + lazy on list) fails and refunds stale runs, and every success update is conditional on the row still being in-flight so swept runs never flip back to ready.
- The sidebar credit balance is a shared react-query key (CREDIT_BALANCE_KEY); invalidate it after any action that can move credits.
- Post analysis runs one stage per request (client-driven advanceAnalysis with a stage_claimed_until lease, partial state in analyses.evidence.partial) because the edge runtime cancels work when the browser disconnects; a pg_cron + lazy sweep fails and refunds the pending attempt after 15 min idle.
- Clone versions are generated on demand (generateCloneVersions, per-attempt charge + refund, free once rows exist), never inside the core analysis, and legacy *Forensics objects are derived in code from evidence to keep analysis output small.
- Analysis reads saved source-media files; video watching and verification are separate persisted Gemini stages, only corrected observations feed Claude synthesis, and first-pass evidence remains diagnostic so drafts can resume without repeating completed paid work.
